# Jaison V J Portfolio

A dependency-free static portfolio ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a GitHub repository named `jaisonvj.github.io`.
2. Upload the contents of this folder (not the folder itself) to the repository root.
3. In the repository, open **Settings > Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Your portfolio will publish at `https://jaisonvj.github.io`.

The site includes the portrait and résumé PDF locally under `assets/`, so it needs no build tooling or project dependencies. It loads its display fonts from Google Fonts when online.
